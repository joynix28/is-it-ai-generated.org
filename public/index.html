    Use it as an API

    The same engine is available as a REST endpoint, an npm package and a CLI.

    Endpoints

    POST /api/detect       { text, language?, sensitivity?, sentences? }
POST /api/count        { text, language? }
POST /api/image        { base64, mime? }  or  { data, width, height }
POST /api/provenance   { base64, mime? }   C2PA + SynthID + OpenAI
GET  /api/health
GET  /api/stats

    Example

    curl -s https://is-it-ai-generated.org/api/detect \
  -H 'content-type: application/json' \
  -d '{"text":"Your text here"}' | jq .score

    npm package

    npm install is-it-ai-generated

import { detectText, analyzeC2pa, scanUnicode } from 'is-it-ai-generated';

    Command line

    echo "text" | isitai
isitai --json article.txt

    About and privacy

    Privacy

    Text and images are processed entirely in your browser.

    Open source

    The full source is on GitHub under the MIT licence.

    Limits

    This is a heuristic index, not proof.

    What runs under the hood

    • Unicode forensics — invisible and zero-width characters, Unicode tag smuggling, variation selectors, homoglyph and mixed-script substitution.
    • Provenance — C2PA Content Credentials parsed from JPEG, PNG, WebP and ISOBMFF, with the claim, actions and signer. Optional OpenAI content provenance.
    • Watermarks — SynthID-Text and green-list statistical detectors. They need the provider key, which is not public; they work with your own key.
    • Stylometry — 16 weighted features including compressibility, burstiness, lexical diversity and structure.

    Made with no ads, no tracking and no nonsense.
