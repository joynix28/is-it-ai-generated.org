    Use it as an API

    The same engine is available as a REST endpoint, an npm package and a CLI.

    Endpoint

    POST /api/detect
Content-Type: application/json

{ "text": "…", "language": "auto", "sensitivity": 1 }

    Example

    curl -s https://is-it-ai-generated.org/api/detect \
  -H 'content-type: application/json' \
  -d '{"text":"Your text here"}' | jq

    npm package

    npm install is-it-ai-generated

import { detectText } from 'is-it-ai-generated';
detectText('Some text').score; // 0-100

    Command line

    echo "text" | isitai
isitai --json article.txt
isitai --counter article.txt

    Endpoints: /api/detect, /api/count, /api/image, /api/health, /api/stats.

    About and privacy

    Privacy

    Text and images are processed entirely in your browser.

    Open source

    The full source is on GitHub under the MIT licence.

    Limits

    This is a heuristic index, not proof.

    Detection model

    Text: 13 weighted stylometric features plus 20+ named slop patterns. Image: metadata provenance, FFT spectrum, noise, channel correlation. All weights are in src/core/ and auditable.

    Made with no ads, no tracking and no nonsense.
